tdfExtract is used for extracting voltage-resolved mobility data from Bruker timsTOF instruments, typically for further analysis using CIUSuite3.
Typical extraction should take ~3-20 seconds per .d file depending on 1) the m/z range and 2) the number and length of each segment.
